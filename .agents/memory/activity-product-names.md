Use `Robotics-fund AVC1`, `Robotics-fund AVC2`, and so on for every activity product, including existing and future products. Assign names automatically in administration; do not allow custom activity names. Stable product names are unaffected.

**Why:** The user confirmed the exact prefix and asked that the format apply to existing and future activity products.

**How to apply:** Sequence activity products independently from stable products. Keep the generated product name consistent across the admin catalog, user-facing product pages, and purchase-position labels.
