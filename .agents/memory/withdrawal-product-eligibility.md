---
name: Withdrawal product eligibility
description: Stable-product requirement for user withdrawals.
---

A user must have at least one active, unrevoked stable-product position with time remaining to request a withdrawal. Administrator-offered stable products qualify too. An activity-only position or a completed stable position does not qualify.

**Why:** the user clarified that an administrator-offered product should also open access to withdrawals; gifts still do not count toward the separate activity-purchase threshold or referral qualification.

**How to apply:** enforce this condition on the server before changing the user's balance or creating a withdrawal, and do not require the position to have been user-funded for withdrawal eligibility.
