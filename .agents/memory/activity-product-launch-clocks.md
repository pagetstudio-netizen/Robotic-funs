name: Activity product launch clocks
description: Country-local launch scheduling rules for activity products.
---

For activity product launch schedules:
- Togo (TG), Burkina Faso (BF), and Côte d’Ivoire (CI) use the same local clock.
- Benin (BJ), Cameroon (CM), and Niger (NE) use the same local clock, one hour ahead of the first group.
- Preserve the countries configured by the administrator; do not add or remove countries to implement the clock mapping.

**Why:** The user specified these country groups and asked to keep the administrator-configured country list.

**How to apply:** Use this mapping when comparing a scheduled launch against a user’s country-local time. Keep release checks on the server so users cannot buy an unreleased product by changing their device clock.
